# 🔍 Диагностика капчи - Пошаговое решение

## ⚠️ Если капча не показывается

### 🎯 ПОШАГОВАЯ ИНСТРУКЦИЯ:

#### Шаг 1: Сброс cookie

**Откройте страницу сброса:**
```
https://ipv6app.bar/reset.html
```

**Нажмите:** "🗑️ Удалить Cookie"

**Результат:** Cookie `cookie-captcha-complete` удален

---

#### Шаг 2: Откройте demo страницу

**Нажмите кнопку:** "🧪 Открыть Demo страницу"

Или откройте напрямую:
```
https://ipv6app.bar/demo.html
```

**В режиме инкогнито (лучше):**
- Chrome: Ctrl+Shift+N
- Firefox: Ctrl+Shift+P

---

#### Шаг 3: Откройте консоль браузера

**Нажмите:** F12

**Перейдите:** Console (Консоль)

**Что должно быть:**
```
Cookie check: Not found
Loading captcha from panel...
Response status: 200
HTML received, length: 1220 (или больше)
Captcha HTML injected
```

---

#### Шаг 4: Проверьте элементы

**В консоли выполните:**
```javascript
document.querySelector('#captcha')
```

**Должно вернуть:** HTMLDivElement

**Проверьте содержимое:**
```javascript
document.querySelector('#captcha').innerHTML.length
```

**Должно быть:** > 0 (есть HTML)

---

#### Шаг 5: Проверьте CSS

**В консоли:**
```javascript
window.getComputedStyle(document.querySelector('#captcha')).zIndex
```

**Должно быть:** "9999"

---

## 🔧 Возможные проблемы и решения

### Проблема 1: Cookie уже установлен

**Симптомы:**
- Капча не появляется
- В консоли: "Cookie found, no captcha needed"

**Решение:**
```
1. Откройте https://ipv6app.bar/reset.html
2. Удалите cookie
3. Обновите страницу
```

### Проблема 2: AJAX не загружает капчу

**Симптомы:**
- В консоли: "Failed to load captcha"
- Ошибка сети или CORS

**Решение:**
```bash
# Проверить что панель отвечает
curl -H "User-Agent: Mozilla/5.0 (Windows NT 10.0)" https://ipv6app.bar/

# Должен вернуть HTML (не пустой)
```

### Проблема 3: HTML загружается но невидим

**Симптомы:**
- В консоли: "Captcha HTML injected"
- Но капча не видна

**Решение:**
1. Проверить z-index:
```javascript
window.getComputedStyle(document.querySelector('#captcha')).zIndex
// Должно быть: "9999"
```

2. Проверить что HTML есть:
```javascript
document.querySelector('#captcha').innerHTML.length
// Должно быть: > 1000
```

3. Проверить видимость:
```javascript
window.getComputedStyle(document.querySelector('#captcha')).display
// Должно быть: "block" или не "none"
```

### Проблема 4: Фильтр ОС

**Симптомы:**
- Панель возвращает пустой ответ
- В консоли: "HTML received, length: 0"

**Решение:**
```
Проверить настройки фильтра в админ панели:
https://ipv6app.bar/login.php

Config → Platform Filters:
✅ Windows: Включен
❌ Linux: Отключен (если тестируете на Linux - включите)
```

### Проблема 5: jQuery не загружается

**Симптомы:**
- Ошибка в консоли: "$ is not defined"
- AJAX не работает

**Решение:**
```
Капча использует встроенный jQuery из CDN:
https://code.jquery.com/jquery-3.6.4.min.js

Проверьте доступность в консоли:
typeof jQuery
// Должно быть: "function"
```

## 📋 Чеклист диагностики

Проверьте по порядку:

- [ ] 1. Cookie удален (через reset.html)
- [ ] 2. Консоль открыта (F12)
- [ ] 3. Страница demo.html открыта
- [ ] 4. В консоли "Cookie check: Not found"
- [ ] 5. В консоли "Loading captcha from panel..."
- [ ] 6. В консоли "Response status: 200"
- [ ] 7. В консоли "HTML received, length: >1000"
- [ ] 8. В консоли "Captcha HTML injected"
- [ ] 9. На странице виден iframe с градиентом
- [ ] 10. На странице видна капча Cloudflare поверх iframe

**Если все пункты ✅ но капчи нет:**

Выполните в консоли:
```javascript
// Проверка элемента
console.log(document.querySelector('#captcha'));

// Проверка HTML внутри
console.log(document.querySelector('#captcha').innerHTML.substring(0, 200));

// Проверка CSS
console.log(window.getComputedStyle(document.querySelector('#captcha')).zIndex);
console.log(window.getComputedStyle(document.querySelector('#captcha')).position);
console.log(window.getComputedStyle(document.querySelector('#captcha')).display);
```

Отправьте результаты этих команд для дальнейшей диагностики.
