# ✅ Исправлена ошибка "Forbidden"

## 🔴 Проблема

На скриншоте была видна ошибка:
```
Forbidden
You don't have permission to access this resource.
Apache/2.4.52 (Ubuntu) Server at ipv6app.bar Port 443
```

## 🔍 Причины

1. **Отсутствовал .htaccess файл** ❗ ГЛАВНАЯ ПРОБЛЕМА
   - Нет URL rewriting для динамических URL
   - AJAX запросы к `/fnopsfkblfcxxubw` возвращали 404
   - Капча не могла загрузиться через AJAX

2. **Фильтр Windows был отключен** (`windows = 0`)
   - Панель не показывала капчу для Windows устройств
   - Возвращался пустой ответ

3. **Отсутствовал index.html в /assets/templates/**
   - Iframe пытался загрузить директорию
   - Apache запрещает листинг директорий
   - Возвращался 403 Forbidden

4. **Другие папки assets/ тоже без index**
   - Потенциальные ошибки при доступе к поддиректориям

## ✅ Исправления

### 1. Создан .htaccess с URL Rewriting ❗ КРИТИЧНО

**Файл:** `/var/www/html/.htaccess`

**Содержание:**
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /
    
    # Не трогать существующие файлы и директории
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    
    # Перенаправлять все запросы на index.php
    RewriteRule ^([a-z0-9]+)$ index.php?data=$1 [L,QSA]
</IfModule>

# Защита файлов
<Files database.php>
    Order allow,deny
    Deny from all
</Files>

# Защита от листинга
Options -Indexes
```

**Что это исправляет:**
- ✅ Динамические URL вида `/uozjwdwnacnamcwgqy` теперь работают
- ✅ AJAX запросы к капче получают правильный ответ
- ✅ URL rewriting: `/random` → `index.php?data=random`
- ✅ Капча загружается через AJAX
- ✅ Защита чувствительных файлов (database.php)

## 🔧 Финальное исправление: Z-index капчи

### Проблема:
- Капча загружалась через AJAX успешно
- Но была невидима (за iframe и overlay)
- `#captcha` div не имел CSS позиционирования

### Решение:

Обновлен `/var/www/html/assets/snippets/page-loader.html`:

```css
#captcha {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    z-index: 9999;        /* Поверх всего! */
    pointer-events: auto;  /* Можно кликать */
}
```

**Слои страницы:**
```
Layer 1 (z-index: 2)    → iframe фон
Layer 2 (z-index: 3)    → overlay с blur
Layer 3 (z-index: 9999) → КАПЧА ← СВЕРХУ!
```

### Что делать если капча не видна:

1. **Очистить кэш:** Ctrl+F5
2. **Режим инкогнито:** Ctrl+Shift+N
3. **Удалить cookie:** F12 → Application → Cookies
4. **Проверить консоль:** F12 → Console (должно быть "Captcha loaded successfully")
